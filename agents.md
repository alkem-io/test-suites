# Test Personas

This document defines the personas used for testing the Alkemio platform.

| Persona name       | Role                  | Membership                           | Resources                                          | Persona description                                                  |
| ------------------ | --------------------- | ------------------------------------ | -------------------------------------------------- | -------------------------------------------------------------------- |
| Host               | Organisation admin    |                                      | 5 Spaces, 3 VC's, 3 template packs, 1 landing page | Buying decision - linked to org - needs to create the space from org |
| Facilitator        | Space admin + lead    | 3 spaces lead, 10 subspaces each     | none                                               | Main responsibility to design the space and oversee the project      |
| Community manager  | Space admin + lead    | 1 space lead, 10 subspaces each      | none                                               | Main responsibility to activate and onboard the community            |
| Project lead       | Subspace admin + lead | 1 subspaces lead, 3 subspaces member | none                                               | Main responsibility to guide the process in a specific subspace      |
| Active stakeholder | Space member          | 3 spaces member, 10 subspaces each   | none                                               | Likes to contribute                                                  |
| Stakeholder        | Space member          | 1 spaces member, 10 subspaces each   | none                                               | Likes to stay informed                                               |
| New stakeholder    | No account            |                                      | none                                               | Wants to explore Alkemio and a particular Space                      |
| Alkemio GA         | Global admin          |                                      | 10 spaces, 10 subspaces each                       | End-responsible for the platform                                     |
| Alkemio SA         | Support admin         |                                      | 10 spaces, 10 subspaces each                       | Offers support on the platform                                       |
